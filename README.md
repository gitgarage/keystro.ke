# keystro.ke

keystro.ke is an open source typing platform focused on developing attention, rhythm, accuracy, and long-term typing skill.

Unlike traditional typing websites that primarily measure words per minute, keystro.ke is designed to understand *how* a person types.

The project aims to become both a useful application and an educational codebase. Every major design decision is documented, the entire development history is public, and the project is intended to be approachable for developers of all experience levels.

---

## Design Goals

- Local-first
- Fast
- Beautiful
- Framework-light
- Educational
- Free to host on Cloudflare
- Open development from the first commit
